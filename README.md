Netradyne is a transportation technology company whose Driver·i platform brings Edge AI and computer vision to commercial fleet safety and management. In-cab camera systems capture 100% of drive time, analyze driving behavior in real time, and drive the GreenZone Score, driver self-coaching, managed coaching, GPS tracking, and vehicle alerts across trucking, delivery, construction, passenger transit, school transportation, and other industries. Netradyne exposes a partner/developer API surface (developer.netradyne.com, hosted on Stoplight, behind sign-in) plus a broad integrations and installation-partner ecosystem, and publishes a security program certified to ISO 27001/27017/27018/27701 and HIPAA. Backed by SoftBank Vision Fund.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
